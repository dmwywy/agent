## 一、项目是什么

**2026 北京市大学生金融人工智能竞赛**参赛作品，主题「金融投研智能体构建」。

作品名：**面向上市公司定期报告的财务报告信息一致性量化核查与研究报告纠错智能体**

技术路线（《项目思路》原话）：**"程序负责计算、模型负责理解"**
- 程序：解析、单位换算、金额校验、规则比对、指数计算——所有数值结论由程序产生
- 模型：科目名语义匹配、文字表述判断、异常原因解释——不产出任何数值

**提交要求**：初赛 = 计划书 PDF + 5 分钟视频（**不归我负责**）；决赛 = 可运行原型 + 完整源码 + 运行说明 + **现场可实时处理的样例数据**。

## 四、五个核查维度（全部可执行）

| 维度 | 含义 | 规则 | 实现 |
|---|---|---|---|
| C内 | 表内勾稽 | BS01 资产=负债+权益；BS02 权益=归母+少数；IS03 净利润=利润总额-所得税；CF01 现金净增加额=经营+投资+筹资+汇率 | `rules_engine.py` |
| C间 | 表间一致 | LJ01 利润表净利润=补充资料净利润；LJ02 现金流量表经营净额=补充资料 | 同上 |
| C期 | 跨期衔接 | XQ_CASH / XQ_AR / XQ_INV：本期期初=上期期末 | 同上 |
| C附 | 主表与附注 | NB01 货币资金=库存现金+银行存款+其他货币资金 | 同上 |
| C研 | 研报引用 | RC01：研报数值 vs 财报数值 | `research_check.py` |

CSI 计算（`interfaces.md §4.5`）：维度得分 =(通过 + 0.5×待复核)÷可执行规则数；
CSI = Σ(得分 × 归一化权重)×100；不适用维度权重按比例分摊。

## 五、★ 关键设计决策（含理由，别改回去）

### 1. `thinking` 必须关闭（最重要）
`deepseek-flash` **默认开启深度思考**，`reasoning_content` 与正文**共享 `max_tokens`**。
实测同一批输入：`enabled` 烧光 8000 token 返回**空正文**；`disabled` 只用 242 token。
差 33 倍，且默认档位会让契约直接失败。写在 `src/llm.py` 的 `THINKING`。

### 2. 推理参数必须全进缓存键
`PARAMS` 里含 `temperature/top_p/max_tokens`，`THINKING` 也参与。
否则改了参数缓存却不失效，会命中旧结果，"可复现"失真。

### 3. 模型不产出数值、不产出位置
- `match_item` / `match_claim` 的 `evidence` 由**程序确定性回填**（一批 40 条，单个 evidence 覆盖不了）
- 异常归因由程序做（是否 10 的整数次幂、是否符号相反），模型只在候选中选并措辞

### 4. 模型措辞不写进结果文件
`results.json` / `csi.json` 必须逐字节可复现。模型解释只写 `explanations.json`，
报告与网页按 `rule_id`/`claim_id` 关联展示。

### 5. 期间不许混
- 资产负债表项目 = 时点（`BAL_END`/`BAL_BEG`），利润表/现金流量表 = 时期（`FY`）
- 附注各小节期间性质不同：货币资金是期末/期初余额（时点），补充资料是本/上期金额（时期）
- 单季数与年度累计不可比（C研 里判 `REVIEW` 而非 `FAIL`）

### 6. 字段缺失判 NA，不判 FAIL
`NA` 不计入分母。"没数据"不能报成"有问题"。

### 7. 报告只呈现，不重算
改规则必须重跑流程；只跑 `report` 不会更新结论。

### 8. 数据隔离
现场解析写 `runs/<run_id>/ingested/`，**不写**共享 `data/`。
`load_structured` 会把目录下所有 json 读进来，堆两批就串数据。

## 六、★ 踩过的坑（同样的问题别再犯）

| 坑 | 现象 | 修法 |
|---|---|---|
| **netguard 拦回环** | 装上后 `127.0.0.1` 被挡，**网页界面直接崩** | 放行 `127.0.0.1/::1/localhost`；补 `uninstall_allowlist()` 供测试还原 |
| **CSI 漏算 C研** | 查出 2 条研报错误，CSI 仍显示 100 分**虚高** | `run_rules` 读 `research_claims.json` 并入 CSI |
| **畸形单位漏检** | "862.3 **亿万元**"数值凑巧在容差内被判 PASS | 单位写法非法单判 `UNIT_SCALE`，数值接近也不放行 |
| **畸形单位崩溃** | 量级字表有 `"千元"` 无 `"千"`，`KeyError` 打断全流程 | 补 `"千"` 并改 `.get` 兜底；单条异常只丢该条 |
| **分部营收误挂总营收** | "茅台酒…**营收** 1495.3 亿"被当成总营收 | 金额按**最近前置指标名**归属；泛化别名（"营收"）移出匹配表 |
| **单季 vs 全年** | "2024Q4 营收 510.2 亿"拿去比年报 1741 亿 → 误报 | 句中带 Q1–Q4/半年 且记录是 FY → 判 `REVIEW` |
| **一条 claim 只返回一个科目** | 句中第二个指标的错误被漏掉 | 提示词要求**每个指标各输出一条 match** |
| **docx 附注标题** | 2024 写 `1、货币资金`，2025 写 `8. 货币资金` | 正则同时接受全角顿号与半角句点 |
| **年报标题错字** | 原件把"现金流量表补充资料"写成"**金**流量表补充资料" | 小节匹配用「包含」而非「相等」 |
| **docx 无固定分页** | 硬编页码等于伪造证据 | 用 `locator`（章节/表号/行号）替代 `page`（`interfaces.md §1.3`） |
| **CLI 静默** | 跑完无输出，使用者以为失败 | `fincheck` 打印运行摘要 |
| **manifest.calls 恒为 0** | README 承诺统计调用次数，字段建了没人写 | 落盘前从 `logs.jsonl` 回算，按 `started_at` 过滤 |
| **pyarrow 列类型** | 网页"得分"列混数字与"不适用" → `ArrowInvalid` | 统一转字符串 |
| **离线指数级拆分** | 缓存未命中触发二分递归，77 次调用 | 只有 `OUTPUT_EMPTY` 才拆分 |
| **测试污染全局** | `install_allowlist` 改写 socket 且不还原，后续测试全挂 | 用 `try/finally` 还原 |
