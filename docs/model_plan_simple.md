# 模型调用方案

适用范围：9/27 至 9/30。本方案覆盖模型名称、API 调用方式、输入文本格式、返回格式、错误处理方式、不联网检索运行边界六项。

## 1. 模型名称

1. 平台：DeepSeek 开放平台，接口协议为 OpenAI 兼容。
2. model 标识：`deepseek-flash`（默认，即 V4.1-Flash）；可选 `deepseek-v4-pro`。
3. 配置位置：`src/llm.py` 顶部 `MODEL_ID`，可由 `.env` 覆盖。
4. 白名单校验：仅允许上述两个取值。写错在模块加载时即报错，不发出任何请求。
5. 版本记录：实际使用的 model 标识与调用日期写入 `runs/<run_id>/manifest.json`。

## 2. API 调用方式

1. `base_url`：`https://api.deepseek.com`。
2. 推理参数：`temperature=0`、`top_p=1`、`max_tokens=1500`、`stream=false`。
3. 结构化输出：`response_format={"type":"json_object"}`；提示词必须含 `json` 字样并给出输出样例。
4. 凭据来源：只从环境变量或 `.env` 读取；日志、报告、manifest 中一律掩码显示。
5. 缓存机制：`cache_key = sha256(提示词内容 + 模型标识 + 推理参数 + 输入数据)`，不含凭据与时间戳。因此同一输入在任何机器上命中同一份缓存，评审无需 API Key 即可复现。
6. 唯一出站入口：`src/llm.py`，其余模块不得直接调用模型接口。

## 3. 输入文本格式

1. 不直接接收 PDF。输入为解析器产出的文本片段与结构化字段，由 `src/inputs.py` 构造。
2. 四类输入：科目归一化、单位与期间识别、研报引用匹配、异常原因解释。
3. 硬性约束：
   （1）每个文本片段携带唯一 `chunk_id`，其与页码的对应关系保存在本地映射表中，模型不生成页码；
   （2）单段文本不超过 4000 字符，超出则切分；
   （3）输入中不含需要判定的数值结果，模型只做语义匹配，数值比较由本地程序完成。

## 4. 返回格式

1. 5 个返回结构定义于 `src/schemas.py`，与 `prompts/<task>.txt` 一一对应，可导出 JSON Schema。
2. 三层校验（`src/validators.py`）：
   （1）枚举白名单：`canonical_item`、`item_code`、`cause` 只能取约定集合内的值；
   （2）证据校验：`chunk_id` 必须来自本次输入，`quote` 必须真实存在于该片段文本中；
   （3）数字白名单：报告文字中出现的一切数字都必须能在程序给定结果中找到同值，否则拒绝。
3. 失败处理：schema 校验失败时携带错误信息修复重试一次；仍失败则该条记 `REVIEW`，不中断整个流程。

## 5. 错误处理方式

| 错误类型 | 是否重试 | 程序动作 | 提示 |
|---|---|---|---|
| 400 格式错误 | 否 | 停止并抛 `ProviderError` | 模型名或参数拼写错误 |
| 401 认证失败 | 否 | 停止并抛 `ProviderError` | Key 无效、含空格或已吊销 |
| 402 余额不足 | 否 | 降级为离线模式 | 改用缓存重放 |
| 422 参数错误 | 否 | 停止并抛 `ProviderError` | 检查 model / max_tokens |
| 429 速率上限 | 是 | 1s/2s/4s 退避加抖动，并发降为 1 | 日志 WARN |
| 500 / 503 | 是 | 同退避策略，最多 3 次 | 日志 WARN |
| 网络超时 | 是 | 同上 3 次 | 日志 WARN |
| 输出非 JSON 或结构校验失败 | 是 | 携带错误信息修复重试 1 次 | 日志 WARN |
| 全部重试失败 | 否 | 该条记 `REVIEW`，继续执行 | 报告列入需人工复核 |

判断原则：4xx 属配置或凭据问题，改了再来，不重试；429、5xx 与网络异常属外部问题，退避重试。

## 6. 不联网检索的运行边界

1. 唯一允许出站：`api.deepseek.com:443`；其余地址由 `src/netguard.py` 拦截并记入 `logs.jsonl`。
2. 离线模式（`--offline`）不读取凭据、不发起任何网络请求，只使用本地缓存重放。
3. 系统不启用网页搜索、网络爬虫与外部数据库检索；本地检索为本地文件文本匹配，无外部请求。
4. 启动自检：`offline_selftest()` 主动尝试连接 API 域名，若可达即报错，说明有模块绕过缓存。

## 7. 验证方式

| 项 | 验证命令或方式 | 通过标准 |
|---|---|---|
| 模型名称 | `python -m pytest -q -k whitelist` | 白名单校验通过 |
| 调用方式 | `python test.py` | 首次输出 `API_OK`，再次输出 `CACHE_HIT` |
| 输入格式 | `python -m pytest -q -k inputs` | 4 个构造函数可用 |
| 返回格式 | `python test.py` | 5 个任务均通过 schema 校验并落缓存 |
| 错误处理 | 演练 401、400、断网各一次 | 截图存 `docs/evidence/` |
| 联网边界 | 访问非白名单地址 | 被拦截并写日志 |
