# 外部标准化模板 → 仓库字段/规则候选映射（2026-10-12）

## 目的和安全边界

本文件根据收到的三份标准化模板、规则表、运行结果与仓库 `rules/fields.yaml` / `rules/rules.yaml` 整理。它是**信息工程候选映射**，用于确定适配器可以如何转换数据；不改财务规则，不改变原始文件，不据此把外部 CSI 定为正式分数。

- “直接”表示字段定义、口径和用途基本相同，可以转换字段编号；仍需保留原始 ID、原始状态和来源证据。
- “条件”表示概念接近，但来源、正负号、公式或粒度不同；本草案不允许直接用于自动规则判定。
- “无映射”表示仓库没有同义字段/规则，或相似字段的含义不相同。应保留原编号并标为未映射，不能丢弃或塞入近似字段。
- 当前运行记录采用 Word 页码和表号定位。仓库接口还要求 `chunk_id` 与原文 `raw_text`，故编号映射本身**不代表证据接口已兼容**。

## 3. 期间转换候选

根据模板的标准化说明及仓库接口枚举转换。原始 `report_period` 与 `period_position` 必须一并保留，不能仅凭 `annual/half_year` 判断余额和累计额。

| 外部记录情形 | 仓库 `period` | 仓库 `period_type` | 解释 |
|---|---|---|---|
| 2024 年报时期数（本期） | `2024` | `FY` | 2024 全年累计流量/利润。 |
| 2024 年报期末余额 | `2024-12-31` | `BAL_END` | 资产负债表期末时点。 |
| 2024 年报期初余额 | `2023-12-31` | `BAL_BEG` | 属于 2024 报告的期初余额。 |
| 2025 年报时期数（本期） | `2025` | `FY` | 2025 全年累计。 |
| 2025 年报期末余额 | `2025-12-31` | `BAL_END` | 期末时点。 |
| 2025 年报期初余额 | `2024-12-31` | `BAL_BEG` | 可与 2024 年报期末记录做跨期衔接。 |
| 2026-H1 时期数（本期） | `2026-H1` | `YTD` | 2026-01-01 至 2026-06-30 年初至今累计；不与全年 FY 直接比较。 |
| 2026-H1 期末余额 | `2026-06-30` | `BAL_END` | 半年度报告期末时点。 |
| 2026-H1 期初余额 | `2025-12-31` | `BAL_BEG` | 半年度报告期初余额。 |

若外部记录只给 `report_period`、未给 `period_position`，则期间类别无法可靠确定，该条不导入规则计算，列为 REVIEW。

## 4. 状态和维度转换候选

| 外部原始状态 | 仓库状态 | 处理方式 |
|---|---|---|
| 核查通过 | `PASS` | 保留原值与证据。 |
| 明确异常/明确不一致 | `FAIL` | 仅当外部规则已成功计算且满足其异常标准时转换。 |
| 需人工复核 | `REVIEW` | 保留原始原因。 |
| 证据不足 | `REVIEW` | 不等于通过，也不伪装为不适用；保留 `evidence_insufficient` 原因。 |
| 口径待确认 | `REVIEW` | 保留 `scope_pending` 原因。 |
| 不适用 | `NA` | 不进入相应规则分母。 |

| 外部维度 | 仓库维度 |
|---|---|
| 表内 | `C内` |
| 表间 | `C间` |
| 跨期间 | `C期` |
| 主表附注 | `C附` |
| 研报引用 | `C研` |
| 专项核查 | 无仓库维度映射；R27 当前不进入仓库规则/CSI。 |

## 5. 当前映射结论

1. 87 个外部字段编号中，有一批可按同义词直接转入仓库字段；无仓库字段的记录必须保留在外部原始数据中，不能丢弃。
