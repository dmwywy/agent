## 4. 约束（已写入代码断言）

1. `type=amount` 的值一律为**十进制字符串**，参与计算前 `Decimal(str(v))`，禁止浮点；
2. `source=NOTE` 或 `MDNA` 的字段，记录必须带 `note_ref` 与 `page`，否则不得进入核查；
3. 「未披露」不写入 JSON，**不用 `null` 或 `0` 表示**；
4. 口径（合并/母公司）与期间（时点/时期）不得混用。
