## 一、项目是什么

**2026 北京市大学生金融人工智能竞赛**参赛作品，主题「金融投研智能体构建」。

作品名：**面向上市公司定期报告的财务报告信息一致性量化核查与研究报告纠错智能体**

技术路线（《项目思路》原话）：**"程序负责计算、模型负责理解"**
- 程序：解析、单位换算、金额校验、规则比对、指数计算——所有数值结论由程序产生
- 模型：科目名语义匹配、文字表述判断、异常原因解释——不产出任何数值

**提交要求**：初赛 = 计划书 PDF + 5 分钟视频（**不归我负责**）；决赛 = 可运行原型 + 完整源码 + 运行说明 + **现场可实时处理的样例数据**。

## 五、★ 关键设计决策（含理由，别改回去）

### 1. `thinking` 必须关闭（最重要）
`deepseek-flash` **默认开启深度思考**，`reasoning_content` 与正文**共享 `max_tokens`**。
实测同一批输入：`enabled` 烧光 8000 token 返回**空正文**；`disabled` 只用 242 token。
差 33 倍，且默认档位会让契约直接失败。写在 `src/llm.py` 的 `THINKING`。

### 2. 推理参数必须全进缓存键
`PARAMS` 里含 `temperature/top_p/max_tokens`，`THINKING` 也参与。
否则改了参数缓存却不失效，会命中旧结果，"可复现"失真。

### 3. 模型不产出数值、不产出位置
- `match_item` / `match_claim` 的 `evidence` 由**程序确定性回填**（一批 40 条，单个 evidence 覆盖不了）
- 异常归因由程序做（是否 10 的整数次幂、是否符号相反），模型只在候选中选并措辞

### 4. 模型措辞不写进结果文件
`results.json` / `csi.json` 必须逐字节可复现。模型解释只写 `explanations.json`，
报告与网页按 `rule_id`/`claim_id` 关联展示。

### 5. 期间不许混
- 资产负债表项目 = 时点（`BAL_END`/`BAL_BEG`），利润表/现金流量表 = 时期（`FY`）
- 附注各小节期间性质不同：货币资金是期末/期初余额（时点），补充资料是本/上期金额（时期）
- 单季数与年度累计不可比（C研 里判 `REVIEW` 而非 `FAIL`）

### 6. 字段缺失判 NA，不判 FAIL
`NA` 不计入分母。"没数据"不能报成"有问题"。

### 7. 报告只呈现，不重算
改规则必须重跑流程；只跑 `report` 不会更新结论。

### 8. 数据隔离
现场解析写 `runs/<run_id>/ingested/`，**不写**共享 `data/`。
`load_structured` 会把目录下所有 json 读进来，堆两批就串数据。

### 9. 时点数与时期数不许直接相加，要按「报告年度」对齐
权益变动表的勾稽要同时用三种期间：未分配利润**期末**（2024-12-31 时点）、
**期初**（2023-12-31 时点）、本年**净利润与利润分配**（FY 2024 时期）。
引擎默认按 `(period, period_type)` 分组取数，会把它们拆进三个组、每组都缺字段而误判 NA。
故引入规则的第三种取值方式 `kind: report_year`：期初记录归属**下一年度**的报告期
（`_report_year()`），三种期间按报告年度合到一期再代入表达式。`fields.yaml` 的 `period`
决定每个字段该取哪一类记录。**新增这类跨期间勾稽时，先想清楚归属年度。**

### 10. 空白行 ≠ 未披露（仅限固定模板表）
现金流量表补充资料是准则规定的**固定模板**，逐行印出全部调节项，空白行表示
"本年无此项金额"（=0），与"未披露"不同。所以 CF02 用 `zero_if_absent` 列出调节项：
取到值就用真实值，没取到按 0 计；`requires` 里的锚点（净利润、经营净额）缺一仍判 NA。
**这个口子只对显式列出的字段开**，不得当成"缺字段就填 0"的通用做法。

### 11. 规则表不能照抄，要按披露口径改写（否则必然误报）
- 规则表第 13 条"利润表净利润 = 权益变动表综合收益总额 − 其他综合收益"：该式只在
  **少数股东其他综合收益为 0** 时才等于合并净利润。改为取"综合收益总额行的未分配利润列"
  （即归母净利润）与利润表归母净利润比 —— 恒等成立，LJ03。
- 规则表第 18 条口径下的"盈余公积期末 = 期初 + 提取盈余公积"**未转录**：2025 年茅台的
  盈余公积还在"（二）所有者投入和减少资本"里被调减 46.23 亿，照抄会误报。已在
  `rules.yaml` 注释里写明为何不转录，避免后人"补全"回去。
- 分部小计**不等于**利润表营业收入（差 2.87 亿其他业务收入），IS04/IS06/IS07 只做
  分部表内部加总，不跨表比营业收入。
